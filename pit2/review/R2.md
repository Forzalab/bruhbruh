# R2 design review: Gates of Babylon ("Figur") @ 54f0c50

Reviewer R2, working independently. Method: I ran `vite preview` on :4817 and drove it with Playwright (Chromium) at 1280x720, 1440x810 and 1920x1080, plus off-ratio sizes 1280x1000, 1440x700 and 1920x1200. I used the palette (opened it, dragged XOR and three Switches onto the canvas), wired S1/S2 into the AND and the AND into the Lamp, toggled A and then B, forced a rejection (a second wire into the lamp), clicked the grid disk twice for toasts, hovered the nodes, the rows and the disk, gave the truth table 5 inputs and scrolled it down and sideways, zoomed the canvas 5 wheel steps, and deleted a part with right-click. I did one keyboard-only pass. I measured with Pillow (runs, edges, WCAG contrast) and checked the text I judge with Tesseract 5.3.4.
Screenshots: `scratchpad/review/r2/`. Scripts: `s1.js`-`s4.js` in the same folder.

## Polish-pass verdict

**Needs more iteration: ready after the owner reviews the flagged items, but NOT ready to ship.** The visual system holds up well. It is disciplined, not generic, and scales exactly (every edge I measured scales linearly across 1280/1440/1920). The weak layer is behaviour. Keyboard users cannot add parts or pick truth-table rows. Error balloons never go away. The open palette covers the starter circuit's inputs. There are also a few layout shifts in the truth table.
Counts: 3 blockers, 11 quality, 12 polish (26 findings). Open decisions for Tony: R2-9 (the disk's icon) and R2-12 (the live-row digit colour).

## Findings

### Pass 1: ai-slop-check

**R2-19**. palette discipline. `src/theme.css:295` `.truth tbody tr:hover td{background:var(--grid,#f2f2f2)}`. Current: the row-hover fill is the canvas grid token #e2e2e2 (1.30:1 on paper), with a stray #f2f2f2 fallback. Proposed: a dedicated `--hover` token (it can equal #e2e2e2), and drop the fallback. Why: slop rule 7, "every colour traces to a token". A token named for the grid now also means "hover", and a later grid retint would silently change the hover. Conf 0.6, **polish**. Shot: `r2/row-hover-1440.png`.

**R2-20**. untokenised colour. `src/theme.css:125` `.disk:hover{background:#000; box-shadow…}`. Current: #000 against --ink #111 (a 1.07:1 difference, invisible). The only hover signal is the ring halo. Proposed: remove the #000 and keep the ink fill plus the ring (or ring only). Why: slop rule 7 (invented colour) and rule 6 (pure black). Conf 0.8, **polish**. Shot: `r2/disk-hover-1440.png`.

**R2-21**. spacing scale. `src/theme.css:94-127,169` (rownum left 16u/bottom 20u/top 26u, disk top 74u, lockup 206/96u, palette group gap 29u+29u, wordmark 55u/-3u). Current: off the 4/8 scale. Proposed: keep optical values where fitted to ref3, but put 26→24/28 and 29→28/32 on the u-scale, or document them as a ref-fit table. Why: slop rule 8 and rhythm rule 1. Swiss grids use module multiples. Conf 0.4 (many are optical fits by design), **polish**.

**R2-22**. type sanity (locked). Roboto Flex is a locked decision, so this is not flagged. Only note: the Tesseract read of every UI string is exact ("TRUTH TABLE", "CIRCUIT | EDITOR", "01", "02"). The fitting did not hurt legibility. Conf 0.9, informational.

No gradients (the pal-list/tt masks are functional fades), no emoji, no left-border cards, no hand-drawn people art. The comic lettering is a locked, deliberate brand choice, not slop.

### Pass 2: hierarchy-rhythm-review

**R2-9**. hierarchy / affordance. `src/App.jsx` `.disk` (aria "Show grid"), `theme.css:121-125`. Current: a 153u solid ink disk with a right arrow is the heaviest interactive mark on the page (ink area about 18,400 px² at 1440). It reads as "go / next / start" (the NYCTA direction arrow), but it only toggles a background grid. Proposed (**DECISION FOR TONY**): keep the disk as the NYCTA route bullet, but either give it a grid glyph, or make it do what the arrow promises (open the palette / start). At minimum, make the pressed state visible: `aria-pressed=true` currently looks identical to false. Why: 5-second test, where the primary action should be the most prominent. NYCTA signage uses arrows only for direction. Conf 0.65, **quality**. Shot: `r2/base-1440.png`, `r2/toast-1440.png` (disk unchanged while the grid is on).

**R2-10**. hierarchy / dead field. `App.jsx` footer `.status` + `.help` (row 03). Current: a 60u numbered band ("03") with no visible content at any time. Status goes to `.sr` only, and `.help p` styles exist with no markup. Proposed: put the help line back (e.g. "DRAG A PART · DRAG PIN TO PIN · RIGHT-CLICK DELETES"), or drop the "03" numeral while the field is empty. Why: Müller-Brockmann numbered fields promise content, and an empty numbered field reads as unfinished. It also hides the only discoverability for right-click delete (R2-6). Conf 0.6, **quality**. Shot: `r2/base-1440.png`.

**R2-7**. rhythm / layout shift. `theme.css:271` `.truth{justify-content:center}`. Current: when the table grows from 4 rows to scroll size, "TRUTH TABLE" jumps from cap-top y≈317 to y≈295 (22 px at 1440), and the header row moves from 392 to 368. Proposed: `justify-content:flex-start` with a fixed top offset (the 2-input position), so the label never moves. Why: rhythm rule 3 (repetition). A title in a fixed field should not move with the content. Conf 0.8, **quality**. Shots: `r2/base-1440.png` vs `r2/tt-scrolled-1440.png`.

**R2-11**. rhythm / half row. `theme.css:280` `.tt{max-height:360u}` vs row height 68 px (1.89944em × 35.8). Current: box 356→716, header 39 px, so 4.7 body rows show. The last row is cut at 716: the vertical switch|lamp rule ends at y=715, and that row has no bottom hairline. Proposed: set max-height to header + N×row (e.g. `calc(39px + 5 * 1.89944em)` in the td font context), or clip to whole rows. Why: the code comment in Truth.jsx promises "never half a row". Rhythm rule 7. Conf 0.7, **quality**. Shot: `r2/tt-scrolled-1440.png` (bottom row "1 1 1 0").

**R2-15**. alignment. Side column right edge. Current at 1440: lockup ink right = 1400, label right = 1244 (short heading, OK), table right = 1417, frame inner = 1437. The lockup is 17 px inside the table's right edge. Proposed: set the lockup (or its tracking) to end at the 1418 column edge, or pull the table in to 1400. Why: rhythm rule 7. Swiss flush edges should share one line. Conf 0.55, **polish**. Shot: `r2/base-1440.png`.

**R2-16**. alignment. `theme.css:271-273`. Current: table rules start at x=981, while label ink and disk ink start at 985/986 (a 4-5 px step at 1440, 4 at 1280, 5-6 at 1920). Proposed: either the label's 4u optical indent goes (so all start at 981), or the table rules start at 985. Why: rhythm rule 7, off by a few px. Conf 0.5 (the 4u may be a deliberate optical overshoot), **polish**. Shot: `r2/base-1440.png`.

**R2-18**. hierarchy / empty start. Initial circuit: 2 switches, AND, lamp, **unwired**, and the balloon points at the tab. Current: a first-time user sees parts but no example of the core idea (wires carrying 1). Proposed: ship the demo pre-wired (A,B→AND→lamp) so the first switch toggle lights orange at once. Why: 5-second test ("know what to do"). Conf 0.45, **polish**. Shot: `r2/base-1440.png`.

**R2-23**. hierarchy / weight mismatch. Palette glyph strokes measure **1 px** at 1440 (`pal-open-1440.png`, y=315: runs (86,1),(124,1)). Canvas part strokes measure 2-3 px, and the tab chevron is a 2 px, 14×24u stroke inside a 44×88 box. Current: the palette reads as a lighter-weight UI than the canvas it feeds. The CSS comment claims equal ink density, but the Pillow runs disagree at 1440. Proposed: set the glyph stroke to ≥2 px (e.g. `max(2px, 3*.41*1.6u)`) and the chevron to about 20×34u. Why: rhythm rule 3 (same objects, same weight) and NYCTA uniform stroke. Conf 0.55, **polish**. Shots: `r2/pal-open-1440.png`, `r2/wired-1440.png`.

### Pass 3: polish-pass (accessibility + interaction states)

**R2-1**. keyboard / BLOCKER. `src/Palette.jsx` (the `.pal-tab` is after `.pal-bar` in DOM order). Current: Tab to "Open parts", Enter opens the bar, then Tab goes to `BODY`, then the disk, then the canvas. Shift+Tab ×3 from there ends on a null-labelled element, and Enter adds nothing (nodes stayed 4). Keyboard users cannot add any part. Proposed: when the bar opens, move focus to the first `.pal-item`, put the tab before the list in DOM order (or use `aria-controls` + a roving tabindex), and make Enter on an item call `onAdd` at a free canvas spot. Why: WCAG 2.1.1 Keyboard. Conf 0.8, **blocker**. Shots: `r2/kb-pal-tab4.png`, `r2/kb-paladd.png`.

**R2-2**. keyboard / BLOCKER. `src/Truth.jsx` `<tr onClick>` with tabIndex -1 (measured). Current: clicking a row sets all switches (a key feature), but rows cannot be focused and have no key handler and no role. Proposed: a roving `tabIndex` on the tbody, where ↑/↓ moves and Enter/Space applies, with `aria-selected` on `.live` and a focus ring (3 px ink inset, as the nodes use). Why: WCAG 2.1.1 and 4.1.2, interaction-states rule 5. Conf 0.9, **blocker**. Shot: `r2/row-hover-1440.png`.

**R2-3**. keyboard. `Palette.jsx`/`App.jsx`. Current: Escape leaves the palette open (tested: `.palette.open` still true). Proposed: Escape closes it and returns focus to `.pal-tab`. Why: a11y audit agent 3 ("modals/overlays close on Escape"). Conf 0.85, **blocker** (it pairs with R2-1 as the overlay pattern). Shot: `r2/kb-paladd.png`.

**R2-4**. feedback / stale state. `App.jsx` `setReject` / `status.phrase` are cleared only by a successful connect or a removal. Current: "THAT INPUT ALREADY HAS A WIRE!" stayed up through 3 part drops, 2 disk clicks, table scrolling and a 1.5× zoom. "PICK AN OUTPUT FIRST!" stayed through a switch toggle and opening the palette. Proposed: clear the balloon after about 4 s (the toast's TOAST_MS), and on any pointerdown or key that starts a new action. Why: interaction-states phase 4, where feedback should reflect the current state. A stale error reads as a live error. Conf 0.85, **quality**. Shots: `r2/tt-scrolled-1440.png`, `r2/zoom-in-1440.png`, `r2/kb-paladd.png`.

**R2-5**. interaction / occlusion. The open palette bar is 100u plus a 12u paper shadow, and it sits over the starter switches (switch node x 81-167, bar 55-155). Current: when open, S1/S2 are hidden and wires come out from under the bar. Playwright's click on "Switch A" was blocked by `.pal-item Add Lamp`. The bar also stays open after a drop, so the user must click the pane to close it. Proposed: move the demo parts right by ≥ bar width (x ≥ 180u), and/or close the bar after a successful drop (it already tucks during drags). Why: an overlay should not hide the work it feeds; HIG transient panel. Conf 0.8, **quality**. Shots: `r2/wired-1440.png`, `r2/lit-1440.png`.

**R2-6**. targets + discoverability. `theme.css:213-223` `.remove` 24×24 px, `display:none` until hover. Current: the target is 24 px (below 44), invisible to touch users, and right-click delete has no visible hint anywhere. Proposed: a ≥44 px hit area (visible glyph can stay 24 via padding/::after), shown on selection as well as hover, plus a help line in row 03 (R2-10). Why: a11y agent 4 (44×44 hit targets) and interaction rule 1 (don't reveal interactivity only on hover). Conf 0.7, **quality**. Shot: `r2/node-hover-1440.png`.

**R2-8**. feedback / overlap. Drop handler (`onDrop`). Current: the XOR dropped at 35%/40% of the canvas landed overlapping the AND gate (XOR top-left tucked under the AND body). No snap-away, no warning. Proposed: nudge to the nearest free grid slot, or show a --ink-2 dotted outline for a collision. Why: interaction-states phase 4 (state changes visible and sane). Conf 0.6, **quality**. Shot: `r2/reject-1440.png`.

**R2-12**. contrast (**DECISION FOR TONY**, adjacent to the locked orange-live-row). `theme.css:303` `tr.live td{background:var(--one);color:var(--paper)}`. Current: white on #ff5a1f = **3.12:1**. The digits are 35.8u bold, so they pass AA large text (3:1) by 0.12, fail AA for normal text, and fail at any font fallback smaller than 18.66 px bold. Ink #111 on the same orange = **6.06:1**. Proposed: keep the orange row (locked) but set its digits in --ink, or darken --one to about #e84a10 (≈3.8:1). Why: a11y agent 1. The margin is essentially zero. Conf 0.6, **quality**. Shot: `r2/base-1440.png`.

**R2-13**. legibility. Balloon and toast lettering. Current: the toast ink band is 12 px tall at 1440 (cap about 10 px), and balloon line caps are about 10-11 px. That is about 9 px at 1280, next to 36u table digits and a 58u lockup. OCR reads it (with "Pick" mis-cased), but it is the smallest text on screen and carries the errors. Proposed: raise the lettering cap to 14u (toasts) / 15u (balloons), keeping the 2:1 ellipse by growing the balloon. Why: hierarchy rule 2. Error text should not be the smallest type. Conf 0.5, **polish**. Shots: `r2/toast-1440.png`, `r2/reject-1440.png`.

**R2-14**. clipping. `.say-part` lives inside the canvas and is clipped by the side column. Current: after zooming 1.5× the lamp's balloon is cut in half at x=959 (ink visible 908-960 only). Proposed: flip the balloon to the left when its box crosses the canvas edge, or render balloons in a frame-level layer. Why: polish (care at edges). Conf 0.75, **polish**. Shot: `r2/zoom-in-1440.png`.

**R2-17**. collision. Lamp hover plus the rejection balloon: the balloon tail tip (y≈437) lands on the delete X tile (846,457), so the two ink marks touch. Proposed: `--ay` a few u higher, or offset the X to the node's top-right corner. Conf 0.5, **polish**. Shot: `r2/reject-1440.png`.

**R2-24**. focus visibility. `.pal-tab:focus-visible{background:ink; outline:none}`. Current: focus = an inverted tile (fine, high contrast), but it is identical to hover, so keyboard and mouse users get the same signal and hover can mask focus location. After Enter opens the palette, focus left the tab and no ring was visible anywhere (`kb-paladd.png`). Proposed: add a 2 px offset ring on focus-visible in addition to the inversion. Conf 0.5, **polish**.

**R2-25**. disabled state. `.pal-item[aria-disabled]` = --ink-2 stroke, `cursor:not-allowed`, but no reason text. Proposed: `title="13 switches max"` (or say it in a balloon). Why: interaction rule 4 (say why it is disabled). Conf 0.5 (not triggered live; code-read), **polish**.

**R2-26**. motion. `.pal-bar`/`.pal-tab` transitions (160/120 ms) are not wrapped in `prefers-reduced-motion` (measured 0.16s under reduce emulation). They are under 200 ms, so this is acceptable by the audit's threshold. The toast is wrapped correctly. Proposed: add them to the existing reduce block for consistency. Conf 0.4, **polish**.

**R2-27**. semantics. The canvas `main` has no heading or label. The wordmark h1 is "Figur", and the only h2 is "Truth table". Screen-reader users get no "Canvas" region name, and nodes are `div`s with no accessible name (only their ports and switches have one). Proposed: `aria-label="Circuit canvas"` on main, plus `aria-label` per node ("AND gate g1, output 0"). Why: a11y agent 2. Conf 0.6, **quality**. Evidence: `s1.js` inventory (node rows show empty labels).

**R2-28**. hint persistence/placement at 1280: the tab keeps its 44 px floor while the bar is 100u = 89 px, so the tab covers 22 px of the bar's glyph column when open (`pal-open` geometry: tab 133-177 over bar ending 155 at 1440, worse at 1280). Proposed: a smaller floor, or push the tab fully outside the bar's rule when open. Conf 0.45, **polish**. Shot: `r2/pal-open-1440.png`.

## Locked decisions: verified, not flagged
