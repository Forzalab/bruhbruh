# Gates of Babylon: deploy branch

Built site for http://csci4x.com:6677. Generated by `scripts/publish-site.sh`
on the main branch. Do not edit by hand.

- `site/`: the built static site. Only this folder is served.
- `serve.sh`: starts or restarts the server. Run it on csci4x.

First time:

    git clone -b deploy/gob-site <repo-url> ~/gob && cd ~/gob && ./serve.sh

After a new build:

    cd ~/gob && git pull && ./serve.sh

Stop: `kill $(cat ~/gob/.server.pid)`. Other port: `PORT=6678 ./serve.sh`.
